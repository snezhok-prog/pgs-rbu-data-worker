Дополнительно в интерфейсе открыты собственные записи НТО, рынка и ярмарки и проверено отображение импортированных данных.

## Исправления по результатам живого прогона

1. HTTP-адаптеру добавлен явный список торговых коллекций. Справочные источники доступны только для чтения; произвольные коллекции отклоняются до HTTP.
2. Бизнес-хеш канонизирует только JSON-числа:7800 и 7800.0 равны по значению. Строки, поля, порядок массивов и настоящие изменения чисел по-прежнему проверяются строго.
3. Группы приложений создаются отдельным subresource после подуслуги; корневой create/PUT documents на текущем DEV группу не сохраняет.
4. HTTP-ошибка теперь сообщает метод и путь без query/body. Для POI подключён SDK-совместимый logging provider, standalone выводит только консоль.

Первый НТО РОИВ потребовал **контролируемого вмешательства оператора**: первоначальный CREATE локального справочника получил 500. Worker запретил слепой повтор. После пяти нулевых поисков подтверждения однократно повторён тот же payload с теми же GUID и operationKey, получен 201, содержимое перечитано; worker продолжил из сохранённого намерения без нового CREATE. Причина первого 500 не установлена. Этот случай не выдаётся за полностью автоматическое восстановление. Другие пять положительных сценариев прошли без операторского создания.

## Локальная проверка и сборка

- Maven verify/package: **62 JUnit**, без ошибок/пропусков, плюс **203** проверки четырёх main-наборов общей логики и рекламы.
- CMD-клиент: **138** контрактных проверок с синтетическим транспортом; отдельно не объявляется полным живым CMD-прогоном.
- Прямая компиляция **70** main-файлов с настоящим SDK прошла. Корпоративная Maven/Spring-сборка не подтверждена: приватный parent недоступен, диагностический bootstrap требует конфигурацию SDK RabbitMQ.
- **258** SDK JAR совпали с зафиксированным артефактом по SHA-256. В standalone20 JAR:12 совпадают с SDK,8 — дополнительные зависимости Excel-парсера. Это не утверждение об идентичности всего DEV-окружения.

## Границы

Все восемь проверенных дел ПГС остались в **process**. COMPLETED относится к Camunda, APPLIED — к результату импорта. Штатный финал дела, native кнопки/права/уведомления и регистрация не проверены. DEV-откат не выполнялся; положительный откат, запреты чужого/изменённого/используемого объекта и восстановление после потерянного DELETE проверены локально.

Это испытания одного worker в разрешённой организации. Межорганизационные права покрыты локально; живой прогон разных кабинетов, распределённые блокировки/CAS, промышленная нагрузка и подключение штатных форм остаются отдельными этапами. Питомец не реализован. Исходные стандарты ПСИ, метарегламент коллеги и существующие чужие записи при этом прогоне не менялись.

После проверки собственный worker и файловый адаптер остановлены. Незавершённых external tasks этого испытательного topic не осталось. Рабочие журналы и подробные доказательства с ID сохранены вне публичного Git.
