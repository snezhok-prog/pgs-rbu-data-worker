# Импорт, валидация и откат РБУ

## Постановка
Цель: расширить проверенный рекламный Java external-task обработчик торговлей. Источники: актуальная ПСИ rbuModules, Groovy/формы импорта, предыдущий trade Java и рекламный worker v1.2 с исправлениями. Проверить соответствие маппинга, ограничения, типы и владельца; убрать Base64 из BPMN. Общие бизнес-классы единственные в src/, корпоративный Spring-проект в корне по шаблону Эволенты, самостоятельная сборка в local-runner/.
Разрешены создание командного репозитория и push исходников; пользователь отдельно разрешил публичную видимость. На DEV разрешены собственные коллекции, дела и процессы, реальные external tasks и XLSX в хранилище ПГС. Менять только собственные DEV-объекты. Не публиковать секреты, выгрузки чужих дел, SDK/JAR и инфраструктурные конфигурации с паролями. Не отправлять сообщения коллегам. Не подменять ручным статусом штатное завершение дела. Реальные журналы и происхождение изменений сохранять.
Критерий готовности: парсинг, валидация, импорт РОИВ/ОМСУ, повтор, граница пакета, управляемые сбои и откат проверены; регресс рекламы проходит; BPMN открыт до deployment; пользователь может повторить через CMD; протокол различает локальный результат и DEV.

## Подтверждённая сверка источников 28.10.2026

- Чтением ПСИ сверены семь стандартов торговли: пять массовых операций и два стандарта работы с одной записью. Все исходные BPMN и 27 Groovy script tasks совпадают с предыдущим торговым Java-модулем.
- У пяти массовых стандартов исходная и опубликованная схемы совпали. У двух стандартов одной записи опубликованное содержимое runtime XSD не вернулось; они не включены в worker v1.
- Три читаемых JSON-ресурса семантически совпадают с декодированными конфигурациями источника. В карте отдельно указаны исходные SHA-256 и SHA-256 форматированных файлов репозитория.
- Подтверждены десять целевых коллекций, включая три зеркальных справочника, серверные зависимости контекста и ограничения исходного импорта. Карта: [docs/trade-source-map.json](docs/trade-source-map.json), границы: [docs/trade-scope.md](docs/trade-scope.md).
- Независимый целевой локальный прогон JDK25 завершился успешно: 10 lifecycle JUnit и 203 дополнительных assertions. Последующее усиление привязки fingerprint подтверждается отдельным финальным общим прогоном; этот ранний независимый результат не подменяет его и не является DEV-протоколом.
- Живые DEV-прогоны фиксируются отдельно по фактическим результатам. Штатные UI/финальные статусы ПГС не подтверждены этой сверкой. DEV-откат не проводится через ручной complete; локальный worker рассчитан на один экземпляр и сохранённый журнал.
